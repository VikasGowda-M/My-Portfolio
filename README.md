# 📖 About

Welcome to my personal portfolio! This website showcases my projects, certifications, documents, blogs, and professional profile in one place. It includes an admin panel that allows me to manage content easily without modifying the code.

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/vikasgowda-m/My-Portfolio.git
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build Project

```bash
npm run build
```

### Deploy

```bash
npm run deploy
```
